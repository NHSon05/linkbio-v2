# Documentation

- Record verified task progress in `docs/TASKS.md` and `docs/project_summary.md`. Include the task ID, changed areas, checks run, observed results, and any remaining blockers.
- Mark a task `DONE` after its acceptance criteria are verified. Record pending or blocked checks with their cause.
- Update `docs/ARCHITECTURE.md` for architecture decisions, `docs/API_Contract.md` for API changes, and `docs/data-model.md` for schema or policy changes. Update `docs/plan.md` when delivery scope or ordering changes.
